mass kg, drag area m², and `mu`, `Crr`, and utilization are dimensionless.

mirror checks 4500 N inertia, 220.649625 N rolling resistance, 159.25 N aerodynamic drag,

## Residual risks

- MATLAB and Octave are unavailable, so MATLAB parsing, all `run_checks.m` assertions, plots,
  callbacks, UI rendering, window replacement, accessibility, and runtime performance remain
  unexecuted.
- The repository declares no minimum MATLAB release. `arguments`, `uifigure`, `uigridlayout`, and
  label `WordWrap` require a sufficiently recent release.
- The Python equation mirror and static source assertions cannot prove MATLAB numerical fidelity.
- UI redraw work was reduced to one selected view and committed slider changes, but responsiveness
  was not measured.
- The CLI completion flag attests that checks passed; it cannot independently execute licensed
  MATLAB or judge the teach-back.
- Malformed learner state is preserved and reported for manual repair rather than automatically
  quarantined. A hard process kill may leave an ignored temporary file, although same-directory
  replacement protects the prior progress file until the final atomic step.
- Learner progress writes are atomic but not serialized across concurrent CLI processes; simultaneous
  local commands remain last-writer-wins. The normal learner workflow is sequential, and no
  concurrency mechanism was added in this bounded P02 repair.
- Prerequisite enforcement belongs to the learner CLI. Direct low-level MATLAB calls such as
  `launch_lesson("P02")` do not consult ignored `.learning/` progress.
- `portfolio status vehicle-dynamics-learning` produced no result before a 15-second local timeout;
  canonical artifacts and Git/CI state were therefore inspected directly.
- HEAD's Quality run passed, but the uncommitted P02 changes have no Portfolio Control or GitHub CI run.
- The aggregate `mu*m*g` model intentionally omits driven-axle distribution, longitudinal load
  transfer, combined cornering, slip, gearing, thermal behavior, and transients. Load transfer and
  combined force remain P03/P04 topics.
- Rolling resistance is deliberately discontinuous at exactly zero speed and does not model static
  breakaway or the near-zero-speed transition.
