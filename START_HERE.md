# Start here

This is the Vehicle Dynamics and Motorsport Engineering interactive MATLAB track. Run `./bin/learn status`, then
`./bin/learn start`. P01 is the reference slice; `curriculum/modules.json` identifies the current
contiguous implemented frontier, and every later scaffold maps one-to-one to a Portfolio Control
batch. A learner session follows read → visualize → move one lever → visualize the change →
read/explain, then a broken case, checks, and teach-back. The learner CLI records completion only
when the command explicitly confirms passed checks and supplies that teach-back.

Use `modules/README.md` for the current module map. `docs/CURRICULUM_AUDIT.md` remains the original
baseline readiness audit.
